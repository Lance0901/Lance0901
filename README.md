# Hi, I'm Lance 👋

**Assistant Technical Manager @ Beckhoff** · 10 years in industrial automation
**Beckhoff 技術副理** · 工業自動化 10 年

I work with TwinCAT 3, EtherCAT and motion control (NC / XTS). Lately I build tools that let AI coding agents drive the TwinCAT engineering environment directly.
日常工作是 TwinCAT 3、EtherCAT 與運動控制（NC / XTS），最近在做讓 AI coding agent 直接操作 TwinCAT 開發環境的工具。

## 🔧 What I'm working on / 正在做的事

- **AI × PLC engineering**：用 AI agent（Claude Code、Codex）自動執行 TwinCAT 3 的 build、deploy、ADS read/write 和測試
- **Motion control**：NC 軸介面函式庫，以及 XTS mover 的派車與碰撞避免
- **PLCopen OOP**：把物件導向的 design pattern 用在 IEC 61131-3 上
